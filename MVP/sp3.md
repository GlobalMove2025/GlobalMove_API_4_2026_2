# 📌 MVP - Desenvolvimento de um dashboard interativo com dados agregados de segurança viária, permitindo análises comparativas entre estados e indicadores de risco em todo o território nacional.


## 🎯 Objetivo do MVP
> Desenvolver uma ferramenta de Power Bi que integre diferentes bases de dados públicas (PRF, DATASUS, DENATRAN e IBGE) para analisar os indicadores de sinistralidade no trânsito com foco em veículos pesados.


---

## 📝 Descrição da Solução
> Inicialmente fizemos pesquisas de dados e desenvolvemos codigo no python para coletar e fazer o tratamento dos dados, e em seguida fazer a conexão dos dados no Power BI, das informações sobre a segurança viária do país, com dados do renaest, PRF e IBGE. Criamos filtros com o local, data e causa dos acidentes.

## 🔑 User Stories (Backlog do MVP)
| ID  | User Story                                                                 | Prioridade | Estimativa |
|-----|-----------------------------------------------------------------------------|------------|------------|
| US1 | Como analista de segurança viária, quero calcular indicadores de segurança viária, para avaliar o nível de risco e gravidade dos acidentes com veículos pesados em diferentes regiões. (Taxa de acidentes, taxa de mortalidade, acidentes por população, acidentes por frota). | Alta       |   2 |
| US2 | Como analista de segurança viária, quero criar um ranking de eficiência em segurança viária para municípios com mais de 250 mil habitantes, para comparar o desempenho das cidades na redução de acidentes. | Alta       |   2 |
| US3 | Como analista de segurança viária, quero comparar acidentes com veículos pesados considerando população e tamanho do município, para realizar análises mais justas entre cidades diferentes. | Alta       |   2 |
| US4 | Como analista de segurança viária, quero visualizar os dados em dashboards interativos no Power BI, para facilitar a interpretação das informações e apoiar a tomada de decisão. | Alta       |   2 |
| US5 | Como analista de segurança viária, quero visualizar os acidentes em mapas interativos, para identificar rapidamente os pontos críticos de acidentes com veículos pesados. | Alta       |   2 |
| US6 | Como analista de segurança viária, quero elaborar um relatório com os principais resultados e insights, para apresentar recomendações que possam melhorar a segurança viária no Brasil. | Alta       |   2 |
| US7 |  	Como analista de segurança viária, quero apresentar os resultados do estudo, para comunicar as descobertas e propostas de melhoria para a segurança no trânsito. | Alta       |   2 |
